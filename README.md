# SIM Niaga · Layanan Mahasiswa

Frontend publik untuk layanan surat, pelacakan tiket, unduh berkas, dan kesiapan sidang. Tidak ada login mahasiswa.

## Menjalankan

```bash
npm ci
npm run dev
```

Data pratinjau disimpan di browser lokal dan tidak tersinkron dengan portal internal. Untuk alur nyata, kedua frontend harus menggunakan backend/API Laravel yang sama.
